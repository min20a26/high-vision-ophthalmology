# High Vision Ophthalmology

A responsive portfolio demo for an ophthalmology practice appointment flow.

## Important

This is a fictional demo. Appointment times, insurance names, prices, phone number, and address are placeholders. The form does not submit or store information. Do not enter real patient or insurance information.

## Update sample details

Edit the PRACTICE_CONFIG object near the top of app.js to update the example plans, sample visit prices, office address, phone number, hours, and appointment times. Verify all details before adapting this design for a real clinic.

## Publish with GitHub Pages

Upload index.html, styles.css, and app.js to the root of a GitHub repository, then enable Pages from the main branch and /(root).
